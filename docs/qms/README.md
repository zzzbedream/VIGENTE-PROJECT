# Vigente — Sistema de Gestión de la Calidad (SGC)

Marco de calidad total para una startup de inclusión financiera responsable. No
es marketing de impacto: son estándares verificables, controles operativos y
gates por release. Construido para que un financiador (SCF, CAF, SDF) o un socio
(Templar, Floid) pueda auditar que el proyecto protege al usuario final.

## Principio rector

El valor social **es** el motor de ingresos (Creación de Valor Compartido,
Porter & Kramer): cada score que habilita crédito justo genera un fee y a la vez
reduce la exclusión. La calidad no es un costo añadido — es la condición para que
el producto sea legítimo y sostenible más allá del grant.

## Marcos de referencia adoptados

- **Cerise+SPTF** — Client Protection Standards + Universal Standards for Social
  and Environmental Performance Management (sustituyen a la Smart Campaign).
- **IRIS+ (GIIN)** — set de Inclusión Financiera (co-desarrollado con SPTF).
- **Ley 21.719 (Chile)** — protección de datos personales y decisiones automatizadas.
- **Algorithmic fairness** — equal opportunity, demographic parity, disparate impact.
- **ODS** 1 / 5 / 8 / 10.
